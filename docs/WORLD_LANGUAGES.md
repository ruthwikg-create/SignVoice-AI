# World language resources — v1.3
The directory has 87 distinct profiles and 91 resource records, with 73 country/territory associations. Its country selector offers all 249 ISO 3166-1 country/territory codes; selections without verified resources show a coverage gap. No country is assigned a fabricated sign language. Country associations are discovery aids, not exhaustive statements about communities or official status.

Source: Universität Hamburg, Sign Language Dataset Compendium v1.5.0, inspected October 9, 2026. The v1.3 expansion adds attributed Benilde Filipino FSL, National Chung Cheng University Taiwan TSL, NID South African SASL, and Deaf Zimbabwe Trust community resources. Each profile and resource retains its source-record URL. Resource metadata is a snapshot; playback availability was not verified for all providers. Provider counts are not claimed as locally indexed signs. The compendium covers documented resources, not every sign language on Earth.

## What users can do
- Browse languages by name, country, region, and saved bookmarks.
- Open real dictionary demonstrations at their providers. Access requirements are shown separately.
- Save notes and self-reported practiced markers on this device; export/import progress.
- Study permission-confirmed MP4/WebM/Ogg videos and PNG/JPEG/WebP images locally. Videos offer slow playback and looping; both can resolve typed practice steps.
- Choose any listed profile for a separate personal isolated-sign webcam vocabulary.
- Import verified per-sign reference catalogs for those profiles. Typed practice uses available indexed entries and shows missing words explicitly.

## Video and data rights
The app does not scrape or redistribute international provider videos. Links are not grants of media rights. Resources with unavailable, restricted or registration-dependent access are identified in the interface. SpreadTheSign prohibits downloading or using its video/data without explicit permission. Lifeprint videos are not copied or embedded. Noncommercial, no-derivatives, attribution and share-alike restrictions differ by provider. Check the linked current terms before copying, embedding, commercial use or model training.

A user must confirm permission and consent before storing a personal lesson clip. Clips remain in browser IndexedDB. Limits: 100 MB per video, 20 MB per image, 500 MB total. Progress exports contain notes/bookmarks only; retain original clip files separately.

## Recognition boundaries
Only the original ASL “I love you” handshape has a bundled pretrained classifier. Every other language requires actual user recordings and a background class. Generalizing the profile selector does not create pretrained models. Hand-only temporal template matching cannot represent all facial, body, grammatical or linguistic differences.

Each profile accepts at most 30 classes including background; imports have a 500-entry total cap. Profiles have stable IDs to distinguish ambiguous abbreviations: Indian ISL = ISL, Irish Sign Language = ISG, Israeli Sign Language = ISR. Arabic Sign Languages is explicitly identified as a resource grouping; International Sign is not treated as a universal substitute for national languages.

The original locally indexed catalogs remain: 15,438 ISL video references, 2,085 ASL lesson links and a 26-letter ASL chart. Other profiles start with source-resource and alphabet-guide links, plus saved/imported references and local lessons. These are not complete per-word indexes. See [Sentence practice](SENTENCE_PRACTICE.md).

## Maintenance
Review source access and rights before importing any new index. Keep stable profile identifiers, provenance, checked dates and exact language labels. Treat all directories as versioned snapshots. Report incorrect country associations and missing languages for review by fluent signers.
